## 📚 Coursework & Tasks Summary

### Homework 01: Pointers & 1D Arrays
Focuses on fundamental memory management using pointers and array manipulations in C++.

| Task | Module | Description |
| :--- | :--- | :--- |
| **Task 1(a)** | Pointer Basics | Inspecting memory addresses (`&num`), pointer values (`ptr`), and dereferencing (`*ptr`). |
| **Task 1(b)** | Pointer Modification | Modifying variable values indirectly using pointer dereferencing. |
| **Task 1(c)** | Pointer Arithmetic | Performing Sum, Difference, and Product operations through pointers. |
| **Task 1(d)** | Array Traversal | Allocating and traversing a 1D integer array of size 5. |
| **Task 1(e)** | Array Analysis | Finding the largest and smallest elements in a 1D integer array. |
| **Task 1(f)** | Array Operations | Counting even and odd numbers across 10 integer inputs in a 1D array. |
